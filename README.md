🐦 MyFlappyBird
A classic Flappy Bird clone built using C# and Windows Forms (WinForms). This project demonstrates core game development concepts like gravity physics, collision detection, and real-time object movement.

🚀 Features
Physics Engine: Realistic gravity and upward thrust mechanics.

Infinite Gameplay: Pipes spawn and loop infinitely to provide a continuous challenge.

Score System: Real-time score tracking as you pass through pipes.

Dynamic Graphics: Custom-loaded sprites for the bird, pipes, and background.

Instant Restart: Press the 'R' key to quickly restart the game after a collision.

🎮 How to Play
Start the Game: Run the project in Visual Studio.

Fly: Press the Spacebar to make the bird flap its wings and fly upwards.

Avoid Obstacles: Don't touch the green pipes or the ground!

Restart: If you hit an obstacle, press 'R' to try again.

🛠️ Built With
Language: C#

Framework: .NET Framework / Windows Forms

IDE: Visual Studio 2022
